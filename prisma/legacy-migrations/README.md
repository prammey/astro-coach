# Legacy migrations (not applied, not active)

These three migration folders were written early in the project but were
**never recorded by Prisma Migrate** — the `_prisma_migrations` table did
not exist in the database at all. The tables they describe were created by
hand instead, and they do not match what actually shipped:

| These migrations say | The live database has |
| --- | --- |
| `id TEXT` with no default | `id UUID DEFAULT gen_random_uuid()` |
| `createdAt TIMESTAMP(3)` | `TIMESTAMP(6)` on `UserAttempt` and `UserQuestionProgress` |

Marking them as applied would therefore have recorded something untrue,
leaving permanent drift that a later `prisma migrate dev` would offer to
"fix" by resetting the database.

They were replaced by `prisma/migrations/00000000000000_baseline`, which was
generated by introspecting the real database and does reproduce it exactly.

Kept here for reference only. Nothing reads this directory — Prisma is
configured to look at `prisma/migrations` (see `prisma.config.ts`). Do not
move them back.
